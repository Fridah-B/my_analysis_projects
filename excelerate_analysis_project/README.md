# Excellerate Data Analysis Project

**Project Overview**
This project analyzes Excellerate data to understand learner engagement, opportunity participation, applications, completion, rewards, and other measures of program performance.

The project was completed as a four-week data analysis workflow, moving from data setup and initial exploration through data cleaning, dashboard development, validation, and final presentation.

The goal was to turn the available data into clear insights that could be explored through an interactive dashboard and communicated through a final presentation.

**Tools Used**
- PostgreSQL
- Google Sheets
- Looker Studio
- Google Docs
- Google Slides

# Project Workflow

The project was organized into four weekly deliverables.

**Week 1 | Data Setup and Initial EDA**

The first week focused on understanding the available datasets and preparing them for analysis.

Activities included

- Reviewing the available datasets
- Understanding the structure and fields
- Setting up the data in PostgreSQL
- Exploring the data
- Identifying initial data quality issues
- Performing initial exploratory data analysis
- Defining areas for further investigation

**Week 2 | Data Cleaning and Validation**

The second week focused on preparing the data for reliable analysis.

Activities included

- Identifying data quality issues
- Cleaning inconsistent values
- Standardizing fields
- Addressing incorrect or unusual values
- Validating the cleaned data
- Performing post-cleaning analysis
- Preparing the data for dashboard development

**Week 3 | Dashboard Development and Validation**

The third week focused on transforming the cleaned data into an interactive dashboard using Looker Studio.

The dashboard includes key performance indicators and visualizations covering areas such as

- Learner participation
- Opportunity sign-ups
- Applications
- Completion
- Opportunity categories
- Duration
- Rewards and scholarships
- Engagement patterns

The dashboard was also validated against the underlying data to ensure that the reported metrics and visualizations were consistent with the analysis.

**Week 4 | Final Presentation**

The final week focused on communicating the results of the analysis.

The presentation summarizes

- Project objectives
- Dataset overview
- Methodology
- Key performance indicators
- Analysis findings
- Dashboard insights
- Key observations and conclusions

**Data Analysis Process**

The project followed a structured analysis process
```text
Data Setup
     ↓
Initial EDA
     ↓
Data Cleaning
     ↓
Data Validation
     ↓
Dashboard Development
     ↓
Dashboard Validation
     ↓
Final Analysis
     ↓
Presentation
```
PostgreSQL was used for data preparation, cleaning, validation, and analysis. Google Sheets was used as part of the data workflow, while Looker Studio was used to develop the dashboard. Google Docs and Google Slides were used to document and present the work.

**Dashboard**

The Looker Studio dashboard brings together the main KPIs and visualizations from the analysis.

It provides an interactive way to explore learner and opportunity data and examine patterns across different categories and measures.
