# Data Analysis Projects
This repository is a collection of my data analysis projects, where I explore real-world and simulated datasets to uncover patterns, answer business questions, and turn data into clear, useful insights.

My projects cover different analytical scenarios and follow a structured approach from data preparation and cleaning through exploratory analysis, validation, visualization, and presentation of findings.

**What You'll Find Here**

The projects in this repository demonstrate my experience with:

- Data cleaning and preparation
- Exploratory data analysis
- SQL and relational databases
- Data validation and quality checks
- KPI development
- Data visualization
- Dashboard development
- Business and performance analysis
- Data storytelling
- Analytical documentation
- Presentation of findings

**Tools and Technologies**

Depending on the project, I work with tools including:

- SQL
- Excel
- Google Sheets
- Looker Studio
- Google Docs
- Google Slides
- Tableau

**My Approach**

I aim to go beyond simply creating charts or calculating metrics. My projects document the process of understanding the data, identifying and addressing data quality issues, exploring meaningful patterns, and communicating findings in a way that is easy to understand.

Where appropriate, projects include supporting documentation, analysis reports, dashboards, presentations, and validation work alongside the final results.

**Project Collection**

Each project is organized separately within this repository. The individual project folders contain the relevant datasets, analysis, documentation, dashboards, and other supporting materials where applicable.

This collection will continue to grow as I work on new datasets and analytical problems.
